# DevOps Engineer Portfolio

A responsive, single-page portfolio with a separate print-friendly résumé page. It uses plain HTML, CSS, and JavaScript, so no build step or package manager is required.

## Files
- `index.html` — portfolio website
- `styles.css` — responsive visual styles
- `script.js` — mobile navigation and profile-link configuration
- `resume.html` — résumé page with a **Print / Save PDF** button
- `resume.css`, `resume.js` — résumé layout and configuration
- `site-config.js` — update the name, email, LinkedIn URL, and GitHub URL in one place

## Personalize before publishing
1. Open `site-config.js`.
2. Confirm the `name` and GitHub URL.
3. Add your full LinkedIn profile URL and professional email address.
4. Review the résumé, especially employer names, employment dates, responsibilities, and measurable achievements. The starter text deliberately does not invent an employer or metrics.
5. Review all skill tags and remove anything you have not used or studied sufficiently to discuss in an interview.

## Preview locally
Open `index.html` in a modern browser. The site is static and can be hosted on GitHub Pages, Amazon S3/CloudFront, or any static web host.

## Generate a PDF résumé
Open `resume.html` and choose **Print / Save PDF**. In the print dialog, choose **Save as PDF**. Verify the final layout and details before sending it to recruiters.
